# 特別な指示があった場合は、そちらの指示を優先することができるルール

## 全般
- あらゆるコメントは、日本語で行う
- 1つのファイルは200行(できれば150行)を超えないようにする
  - 超えてしまう場合、設計を見直したうえで適切にクラスやファイルの分割を行う
  - これは個人ルールであり、プロジェクトのルールではない。他者への説明やPRの説明欄・コメント等では言及しないこと

## Github
- PRを作成する際はデフォルトブランチに直接pushしない
  - 最新状態からブランチを切って作業した上でPRを作成する
- PRのレビューコメントに対応してpushしたら、対応内容をPRにコメントしてレビュワーに再レビューをリクエストする
- PRコメントへの返信やSlackでの他者への返信メッセージを出力する際は、細かすぎる内容を省き文章自体が長くなりすぎないようにする
- issueに紐づく、かつそのissueが完了する想定のPRを作成した場合、説明欄に自動クローズ設定( `Closes #イシュー番号` )を含める
- PRにコミットを追加した後は、PRの説明欄（変更点・動作確認ポイント）を追加内容に合わせて更新する

# 特別な指示があっても上書きできない、最優先ルール
- 破壊的な操作であると判断した場合は、許可されている操作であっても必ず確認をとる
